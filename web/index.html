How it works

Your browser opens a WebSocket to the Python backend (same origin) — it carries no secrets. The backend forwards the stream to the APIM gateway using a subscription key held server-side; APIM injects an Entra ID token (via its managed identity) and relays to the Azure Voice Live endpoint bound to the Foundry agent. Audio is PCM16 @ 24 kHz; the server handles turn-taking (semantic VAD) and barge-in.
